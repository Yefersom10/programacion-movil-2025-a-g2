# Introducción a HTML y CSS

Etiquetas y elementos
HTML se crea con elementos. Los elementos son pares de etiquetas que encapsulan o envuelven texto. Las etiquetas se componen de corchetes de apertura y de cierre con un nombre de etiqueta en el medio. Un elemento normalmente incluye una etiqueta de apertura y una etiqueta de cierre.

Por ejemplo, los desarrolladores utilizan la etiqueta de énfasis para destacar palabras en una página.

- El nombre de etiqueta de una etiqueta de énfasis es em.

- Los desarrolladores escriben <em> como etiqueta de apertura para el elemento de énfasis. 

- Una etiqueta de cierre es como una etiqueta de apertura pero incluye una barra inclinada delante del nombre. La etiqueta de cierre del elemento de énfasis es </em>.

## Anidamiento de elementos

Los desarrolladores pueden anidar los elementos HTML de la misma forma que anidaría las bolsas pequeñas y la maleta. El anidamiento se produce cuando los desarrolladores incluyen elementos HTML entre otros elementos HTML. 

## La anatomía de una página HTML

Las páginas web a las que acceden la mayoría de los usuarios cuentan con texto interesante, gráficos fantásticos y vídeos atractivos que conforman el contenido de la página. Cada uno de estos elementos de contenido está incluido en etiquetas HTML. Sin embargo, hay elementos de una página HTML que los usuarios no ven y que componen la estructura de la página.

## Introducción a los atributos

Los atributos modifican los elementos HTML. Los desarrolladores web utilizan los atributos para cambiar el estilo del elemento, establecer una propiedad como a dónde una etiqueta de ancla debe enviar al usuario e incluir metadatos para que los utilice un programa de script.

## Atributos de los atributos

Algunos atributos HTML funcionan de la misma forma. Muchos atributos también tienen sus propios atributos (también llamados propiedades) que puede establecer.

- El "padre" es un atributo del elemento.

- Los atributos "hijo" son modificaciones que puede establecer en el padre.

## Atributos más comunes

Los atributos que utilizará como desarrollador web pueden variar considerablemente según los elementos que necesite incluir en función de su diseño. Sin embargo, existe un conjunto de atributos comunes a muchos elementos que utilizará con frecuencia, como por ejemplo:

- Atributos de estilo y diseño

- Atributos de acción

- Atributos de suceso


## ¿Por qué organizar el código es importante?

es importante organizar el código y el contenido en la página. Organizar el código ayudará a los usuarios y le ayudará a usted como desarrollador. Usted se beneficiará de organizar el código. Los usuarios se beneficiarán de la organización de la información.

### ¿Cómo ayuda la organización de la información a los usuarios?

La información es más fácil de encontrar. Organizar la información para los usuarios es una responsabilidad distinta a las de escribir, documentar y mantener la legibilidad del código. Un diseñador UX puede asesorar sobre el diseño de un sitio que el desarrollador debe entregar para facilitar a los usuarios la búsqueda de lo que necesiten. Un diseño organizado de la información tiene estas características:

- Los elementos similares están agrupados.

- Hay suficiente espacio negativo (áreas donde no hay contenido) para facilitar la lectura.

- Hay una utilización razonable y reflexiva de los menús.

- La utilización de las fuentes y los colores es cuidadosa y coherente.

## Técnicas de organización que ayudan a los usuarios

Garantizar que las páginas web tengan un diseño y una estructura claros puede ayudar a los usuarios no sólo a encontrar lo que necesiten, sino también a que disfruten del tiempo que pasen en el sitio. Cómo distribuye la información en el sitio forma parte de la arquitectura de información (AI). La arquitectura de información es el plan de cómo se organiza la información en el sitio, cómo se vinculan las distintas partes, cómo los usuarios acceden a la información y cómo la presenta.

## ¿Qué es CSS?

El estilo de un sitio web incluye todo, desde la paleta de colores hasta las fuentes que ven los usuarios. Los desarrolladores web añaden estilos a sus sitios mediante estilos en línea o una hoja de estilo.

- Los estilos en línea se aplican en el nivel de elemento mediante el atributo style.
- Una hoja de estilo es una colección de estilos.

## ¿Cómo se aplican los estilos en cascada?

Los estilos CSS se comportan de forma similar. Como ha visto, los elementos pueden estar en relaciones padre-hijo. Estas relaciones repercuten en la aplicación del estilo en los elementos de una página web.

### Estilo heredado

En HTML, los elementos hijo heredan los estilos de los elementos padre.

- Un elemento hijo es aquel que está envuelto por uno o varios elementos.

- Un elemento que envuelve a otro elemento es padre de ese elemento.

## Estilo sustituido

Los elementos hijo pueden sustituir algunos estilos de los elementos padre. Un estilo se sustituye si el elemento hijo implementa los mismos estilos del padre usando un valor distinto. Si un estilo puede tener solo un valor, como un estilo de color, el elemento hijo sustituirá el estilo del elemento padre.

## ¿Cómo funcionan los estilos en línea?

Los desarrolladores web pueden aplicar un estilo en línea a un elemento utilizando el atributo de estilo con cualquier número de atributos hijo. Los estilos en línea son útiles para sitios web sencillos que utilizan un número limitado de estilos.

## ¿Cómo funcionan las hojas de estilo?

Las hojas de estilo son una colección de dos o más estilos. Los desarrolladores web que crean sitios web con más de unas pocas páginas normalmente ponen sus estilos en un archivo separado con una extensión .css. Esto se denomina una hoja de estilo externa.

### Hojas de estilo externas

HTML es muy útil para enlazar a otros recursos en lugar de incluir todo lo que una página necesita en la propia página. Si un desarrollador web necesita incluir una imagen en una página web, puede utilizar un elemento image y apuntar a un archivo de imagen.

## Tipos de estilos de una hoja de estilo

Los desarrolladores web tienen distintas opciones para implementar los estilos en los sitios web. A veces, un desarrollador crea una hoja de estilo que quiere utilizar solo en un único elemento.

## Utilización de los selectores CSS

Los crean en la sección de cabecera de las páginas HTML en una hoja de estilo interna o en un archivo separado con una extensión .css y hacen referencia al archivo en la sección de cabecera de una hoja de estilo externa.

## ¿En qué consiste el modelo de cuadro CSS?
Los desarrolladores web pueden utilizar una tabla para diseñar un página o una sección de una página, pero el uso de tablas no se considera una buena práctica. Presenta algunos desafíos, como la falta de flexibilidad.

En su lugar, la mayoría de los desarrolladores web utilizan el modelo de cuadro CSS para imitar el comportamiento de una tabla con columnas y filas, pero con una mayor flexibilidad.
