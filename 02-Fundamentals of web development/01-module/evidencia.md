## Descripción general del desarrollo web y del diseño web

El desarrollo web incluye todo el trabajo que conlleva crear y mantener páginas web y sitios web. El desarrollo web incluye escribir código para diseñar una página web, añadir fuentes y colores y hacer que el sitio web sea interactivo. 

El diseño web también es una parte importante del desarrollo web. Se centra en cómo se presentan al usuario los elementos de una página web o de un sitio web.
