# ¿Qué es el código abierto?


El término código abierto se refiere a algo que las personas pueden modificar y compartir porque su diseño es de acceso público.

## ¿Qué es el software de código abierto?
El software de código abierto es un software con código fuente que cualquiera puede inspeccionar, modificar y mejorar.

"Código fuente" es la parte del software que la mayoría de los usuarios de computadoras nunca ven; es el código que los programadores de computadoras pueden manipular para cambiar la forma en que una pieza de software—a "programa" o "aplicación"—works.

## ¿Cuál es la diferencia entre el software de código abierto y otros tipos de software?

Algunos programas tienen un código fuente que solo la persona, el equipo o la organización que lo crearon, y mantienen un control exclusivo sobre él, pueden modificar.

## ¿El software de código abierto solo es importante para los programadores informáticos?
No. La tecnología de código abierto y el pensamiento de código abierto benefician tanto a los programadores como a los no programadores.

Porque los primeros inventores construyeron gran parte de Internet en tecnologías de código abierto —like el sistema operativo Linux y el Aplicación de servidor web Apache—cualquiera que use Internet hoy se beneficia del software de código abierto.
