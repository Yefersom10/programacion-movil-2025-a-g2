# Creación de sitios web dinámicos con JavaScript

## Crear la página: JavaScript y sus usos
JavaScript es un potente lenguaje de programación con el que los desarrolladores web pueden cambiar el contenido de un sitio web en función de sucesos, cambiar el estilo de un sitio web e incluso gestionar los datos y proporcionar comentarios a los usuarios. Cada vez que rellena un formulario en un sitio web o utiliza un mapa interactivo, es probable que se esté ejecutando código JavaScript detrás de esa interacción. 

## Utilizar JavaScript con HTML
JavaScript es un lenguaje de programación. Por lo tanto, cuando escribe JavaScript, está escribiendo código. El concepto de poner código en HTML puede parecer extraño, pero la capacidad de añadir JavaScript a su documento HTML es enormemente eficaz. JavaScript es un lenguaje interpretado, lo que significa que mientras se carga una página web, el explorador lee el JavaScript que usted escribe y luego ejecuta cada línea de una en una.

## Utilizar JavaScript para modificar HTML

Los desarrolladores pueden utilizar JavaScript para manipular estilos de página e incluso para reemplazar dinámicamente toda la hoja de estilo CSS. Si asignan un id a un elemento, pueden utilizar JavaScript para buscar elementos por ese ID y luego modificar el elemento. 

## Utilizar JavaScript para reaccionar a las acciones de los usuarios

Los sucesos son cambios del sistema que se han producido. Los motivos de estos cambios pueden ser una modificación en los datos, una interacción del usuario, un error u otros. Los desarrolladores pueden utilizar JavaScript para responder a este tipo de sucesos.  

## Modelos de programación JavaScript
Los desarrolladores web crean funciones JavaScript para responder a los sucesos en una página web. De hecho, las funciones son una parte esencial del modelo de programación JavaScript. Es difícil categorizar JavaScript en un único modelo de programación porque puede funcionar de diversas formas.

## Programación funcional
Los programadores informáticos consideran JavaScript tanto un lenguaje orientado a objetos y como un lenguaje funcional.  

- JavaScript es un lenguaje orientado a objetos porque los desarrolladores lo utilizan para crear objetos y modificarlos.   

- JavaScript es un lenguaje funcional porque los desarrolladores utilizan funciones para la mayoría de las tareas, incluida la creación de objetos. 

Una función es similar a un método en la programación orientada a objetos.   


- Es un conjunto de código que puede aceptar una entrada, realizar algún trabajo y devolver una salida.   

- Para utilizar una función, un desarrollador la llama desde otro código de software. 

- Llamar a una función significa ejecutar el código en la función.  

- Si bien las funciones no están asociadas con los objetos, los métodos sí lo están.

## ¿Qué es Node.js?
Node.js es un entorno de ejecución basado en JavaScript que está disponible gratuitamente en Internet. Los desarrolladores pueden descargarlo y modificarlo gratuitamente. Este modelo de distribución de software se conoce como software de código abierto.

## Las ventajas de Node.js
Node.js se escribió para resolver problemas específicos con objetivos claros de diseño. Un problema que resuelve Node.js es la eficiencia del proceso de solicitudes. Muchos servidores web consumen muchos recursos informáticos, especialmente cuando reciben muchas solicitudes. Como entorno de ejecución, Node.js está diseñado para manejar muchas solicitudes de forma rápida y eficiente.
