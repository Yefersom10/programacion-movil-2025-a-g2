## Descripción general rápida de HTML
El primer paso para crear la página web es desarrollar una base sólida para la estructura de la página web con HTML. Los elementos HTML son los cimientos sobre los que creará toda la página.  

Ha creado archivos HTML, CSS y JavaScript vacíos y ha utilizado VS Code para el proyecto web. Ya está listo para empezar a estructurar la página web utilizando HTML.  

### Simulación: Utilizar HTML para aplicar estilo a una página

- Ha configurado el documento HTML con los elementos <!Doctype>, <html>, <head> y <body>. 

- Ha añadido referencias al archivo CSS y JavaScript en la sección de cabecera del documento. 

- Ha revisado la configuración del direccionador del cliente y ha tomado notas.     

- Ha configurado un contenedor para el contenido.

- Ha dado un nombre a la página web.
