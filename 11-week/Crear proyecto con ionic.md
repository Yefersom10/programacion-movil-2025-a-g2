# Creacion de proyecto con ionic

Instalar el Ionic
````
npm install -g @ionic/cli
`````
### comandos ionic

````
ionic start
````
1. si sale : Use the app creaation wizard?. Escribimos : N

2. Nos dara la opcion de escoger el framework que queremos usar:

    - Angular
    - React
    - Vue

3. Escogemos uno y nos pidira el nombre del proyecto

4. nos mostrara las plantillas pretediminada con las siguientes opciones:
    - tabs
    - sidemenu
    - blank
    - list
    - my-firds-app
5. nos dara de usar modulos(el proyecto en angular)
    - NgModules
    - Standalone

6. para crear compentes o pages secribimos el comando
````
ionic generate
````

7. para arrancar el proyector

````
ionic serve
````
